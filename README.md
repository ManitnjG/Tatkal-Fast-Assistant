# Tatkal Fast Assistant

Native Android booking-preparation companion for the official IRCTC flow.

Features: quick journey preparation, passenger preset field, AC/non-AC opening-time reference, IRCTC eWallet preferred payment, readiness reminders, one-tap official IRCTC handoff, and automatic APK builds.

CAPTCHA, OTP, final payment authorization and ticket confirmation remain manual on IRCTC. This project does not bypass queues, rate limits, CAPTCHA, or other IRCTC protections.

## Install
Open Actions, choose Build Android APK, open the latest successful run, download the Tatkal-Fast-Assistant-debug artifact, extract it, and install app-debug.apk on Android.
